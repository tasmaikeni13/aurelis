# AURELIS Phase 4: Updated Novelty Comparison

| Prior Art Baseline | Shared Concepts | Proposed Difference | Phase 4 Empirical Reality |
|---|---|---|---|
| **ResKV (arXiv 2607.29591)** | Restores omitted numerator and denominator statistics within a cache budget. | AURELIS introduces a delayed solve-free recurrent state S to predict unread observations and derives a deterministic normalizer error bound Eq. (10). | ResKV's intuition that unread mass can be compensated is valid, but using a recurrent matrix S to predict unread values does not outperform per-page static center statistics (Eq. 13). |
| **Quest (arXiv 2406.10774)** | Query-dependent page key coordinate bounds [k^-, k^+] for sparse page selection. | Quest selects top-K pages based solely on max key score without error bounds. AURELIS introduces residual-sensitive priority heuristic and deterministic certification. | Value-sensitive selection prevents catastrophic errors when low-mass pages contain huge value outliers, but Quest's simple key-bounding remains a cheaper page filter. |
| **Certified Quantized Attention (arXiv 2605.20868)** | Runtime error certification with fallback to exact data. | Quantized attention certifies quantization noise in stored keys/values. AURELIS certifies complete structural omission of unread remote pages. | Quantization error certification is tightly bounded and useful; structural omission certification requires conservative exponential intervals that often force full reads unless tolerance is loose. |
| **Hybrid Recurrent Architectures (Based, Infini-attention, NHA, Nemotron-H)** | Couples recurrent state with recent attention window cache. | Hybrids use heuristic linear or learned fusion. AURELIS investigated mass-consistent archive completion to guarantee full softmax recovery in real arithmetic. | The solve-free recurrent state S is efficient in bounded mode (O(d_v d_k + w(d_k + d_v))), but coupling it to an exact archive for certified retrieval adds overhead without beating static page summaries. |
